# library_management_system

# Project overview
I have created a database to mimic a library management system and created multiple functions designed to access different information from the database.

# Technologies used 
- Python
- SQL
- sqlite3
- SQLite

# Concepts demonstrated 
- Python functions
- SQL querys
- Relational database design 

# How to run 
1. Run the database creation script to create and populate the SQLite database.
2. Run the Python program.
3. Call the desired functions with the required arguments.
